The Corridor (PWA 3D game)

Made by Shan & Rajeen.

Put it on GitHub
Create a repo, upload ALL files/folders (index.html, game.js, sw.js, manifest.json, icons/).
Settings -> Pages -> Deploy from branch -> main / root -> Save.
Open https://YOURNAME.github.io/REPO/ and check it runs.
Paste that URL into pwabuilder.com -> Package for Android.
Controls

Phone: arrow buttons walk, drag on screen to look, "I" interacts. PC: WASD/arrows walk, drag mouse to look, E / I interacts.

Change story text: say('...') in game.js. Game name: manifest.json + index.html.
